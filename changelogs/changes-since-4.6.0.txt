Changes since v4.06.00
======================

For v4.06.01
------------

Improvements:
* ACS GetCVar and GetCVarString no longer sound errors when given local, non-server user variables.
  Now they'll just return the hardcoded default values always. This was needed because WADs like
  Hell Revealations (hrs.zip) actually check the existence of specific variables just to determine
  the current port, discarding the actual result.
* Added input checking for WAD files, to prevent crashes or lock-ups on loading corrupted or plain
  invalid data as WADs.
* Fixed so the author name no longer renders under the level name when it's specified by graphics.
  It will only show when specified by text. This is to align with the situation from:
  https://github.com/doom-cross-port-collab/umapinfo/issues/12, and because it's too likely for the
  level graphics to have the author name drawn inside it, causing duplication if the author setting
  in map info also exists.

Bug fixes:
* Fixed crash or corruption occasionally happening when exiting map with sloped 3DMidTex lines.
* Fixed inconsistent clipping behavior with sloped 3DMidTex lines.
* Fixed subtle bugs with portal-aware line hit physics. Most notably, polyobjects with portals can
  once again be walked above when they're below portals (HOM aside).
